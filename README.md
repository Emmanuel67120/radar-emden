# Radar EMDEN

Radar EMDEN est un outil privé de veille, de détection et de qualification d'opportunités commerciales.

Il peut exploiter différentes sources publiques, notamment des offres d'emploi, afin d'identifier des signaux de recrutement, de transformation et de projets.

Les données collectées sont utilisées uniquement à des fins internes de veille et de développement commercial.

Aucune redistribution publique des données collectées n'est réalisée.
